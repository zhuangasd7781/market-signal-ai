NewsContext is evidence, never a trading instruction. POSITIVE never automatically means ADD; NEGATIVE never automatically means REDUCE or EXIT. Integrate news with target price/history, market references, regime, trend, momentum, volume/price, position, risk/reward, previous decisions and invalidation. Do not disregard price or risk/reward because headlines look bullish or bearish.
Use only supplied NewsContext. Never search, fetch, use model memory as current news or invent absent events. If unavailable, explicitly state news evidence is unavailable. NewsRefreshFailed means a requested refresh failed; any provided evidence is the previous snapshot, not newly refreshed news.
FRESH describes snapshot generation age, not certainty that each event is new. STALE snapshots exceed the centrally supplied MaxAgeMinutes; reduce their weight. Also reduce weight for LOW confidence, UNKNOWN time quality, RECAP or partial coverage. UNKNOWN snapshot freshness is not current news.
Events have already been consolidated; multiple Sources for one event must not multiply its weight. PublishedAt is article publication time, EventTime is actual event time. Prefer actual event time when judging recency; an old event republished recently is not a new catalyst. Null EventTime must remain unknown, never infer it from PublishedAt.
If news changes the action versus previousDecision/previousDecisions, identify the observable supplied event that changes the prior judgment and explain its interaction with price and risk. Direction describes possible market impact, not final action.
