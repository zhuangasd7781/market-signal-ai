# Taiwan market context (Task 7)

The runner obtains one normalized, dated Taiwan market context before invoking any analyst. OpenAI and DeepSeek receive that same object. The existing `InputSnapshotJson` stores the full observation, including values, units, source, market date, fetch time, status and data quality. The history API exposes this sanitized context through its existing analysis detail projection. No database migration is needed.

The official TWSE English JSON reports are used because their column labels and units are explicit. On 2026-10-02 the following public requests returned `stat: OK` and were checked against the parser:

| Evidence | Official report | Frequency and unit |
| --- | --- | --- |
| Market turnover and 5D/20D averages | [FMTQIK](https://www.twse.com.tw/en/exchangeReport/FMTQIK?response=json&date=20261002) | Monthly daily rows; `Trade Value` in NTD, distinct from `Trade Volume` |
| Stock breadth | [MI_INDEX](https://www.twse.com.tw/en/exchangeReport/MI_INDEX?response=json&date=20261002&type=ALL) | Daily `Net Change of Price (Number of Listed Securities)` table, **Stocks** column, including parenthesized limit counts |
| Market and target margin | [MI_MARGN](https://www.twse.com.tw/en/exchangeReport/MI_MARGN?response=json&date=20261002&selectType=ALL) | Daily; market financing value is **thousands of NTD**; target financing and short balances are **TWSE trading units** |
| Market institutional flow | [BFI82U](https://www.twse.com.tw/en/fund/BFI82U?response=json&dayDate=20261002&type=day) | Daily buy less sell, NTD; dealer proprietary and hedge rows are summed |
| Target institutional flow | [T86](https://www.twse.com.tw/en/fund/T86?response=json&date=20261002&selectType=ALLBUT0999) | Daily `00631L` row, net shares for foreign, investment trust and dealer |

The `MI_INDEX` response also contains tables without a `title`; the parser selects the named stock-breadth table without assuming every sibling has one. A fixture reproduces this response shape.

These reports are end-of-day releases. In particular, TWSE [describes its margin report](https://wwwc.twse.com.tw/exchangeReport/MI_MARGN?date=20210422&response=html&selectType=MS) as an evening aggregate that may be revised. Each section is dated independently; a previous trading day's observation is `STALE` against a newer target quote and must not be described as today's activity. `PARTIAL` means usable current data exists but the 20-trading-day calculation is incomplete. `UNAVAILABLE` means no usable report was obtained. Missing derived values remain `null`, never zero or synthesized. The AI skill treats every item as evidence and never maps an indicator directly to an action.

The provider requests the current and previous two monthly FMTQIK reports, derives up to 21 actual trading dates, then requests daily reports for those dates. 5D/20D statistics are calculated only when the exact required reports exist. Each report failure is isolated to its affected section. A successful HTTP JSON response is cached for 15 minutes within the provider; each analysis batch also reuses a target's normalized context across users and analysts. The current implementation does not persist an official-data cache across process restarts. A fresh analysis may therefore need roughly 60 daily TWSE requests, and partial history may result when TWSE is unavailable or rate-limits requests. No nonofficial fallback is used.
